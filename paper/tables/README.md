# Paper tables

The rows of each table. The caption and label sit in the section file that
includes the table. Table IV of the paper lists the file each table's numbers
come from.

| File | Table |
|---|---|
| `tab-benchmark.tex` | Table I: the benchmark: rows per window, the primary set, news and sports shares, depth cut points. |
| `tab-crowd.tex` | Table II: forecasts leaning with or against the market, with accuracy and returns. |
| `tab-absolute.tex` | Table III (appendix): absolute scores and skill against simple baselines. |
| `tab-reproducibility.tex` | Table IV (appendix): which script or released file produces each result. |
| `tab-roster.tex` | Table V (appendix): the eight models, their windows, hosts, precision, thinking settings, failures and cost. |
